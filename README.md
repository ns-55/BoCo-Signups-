# BoCo-Signups
Project Topic:
BoCo is a non-profit based in Santa Barbara that aims to bring joy into people's lives by using flowers from growers around Santa Barbara County that are destined for the dumpster to make bouquets to deliver to terminally ill patients, families going through tough times, or someone in need of cheer. This non-profit is in its early stages, and for it to run efficiently, the coordinators need to be able to store all of their volunteer data in one location that is easily accessible. That is the first step of this project, and eventually it will be paired with a platform where volunteers can enter their personal information, sign up, and check in and out; this data will be sent to one location to be accessed by the BoCo coordinators. 
Problem Statement:
At the moment, all communications regarding personal information, sign-ups, and volunteering are conducted manually and are all disconnected; therefore, the BoCo coordinators have no way of consolidating all the information about their volunteers or any local area to access volunteer information. 
Dataset:
At the moment, I have created a fake dataset that models the data we will be collecting once this project is finalized. The entries we will be tracking are:
  volunteer_id
  name_first
  name_last
  email
  phone
  ref_name
  event_date
  sign_up
  time_in 
  time_out
Data Analysis and anticipated results/usage:
This project will allow the coordinators to pull any information needed about their volunteers. It will also allow them to see trends from these volunteers, whether that is what days of the week they volunteer, how frequently they volunteer, whether they tend to no-show after signing up to volunteer, whether they come late and leave early, whether one person refers many new volunteers, etc...
Methods:
  Excel (.csv file of sample data)
  Python (pandas) - data cleaning 
  SQLite - storage
  Power BI and Tableau - dashboard 
  Basic numbers, stats, and graphics
